# UFRO v8.1 Engineering Logic Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild UFRO v8.1 so mass balance, water quality, recycle loops, routing, dilution, Phase 1.0/1.5 integration, and OPEX are engineering-consistent and regression-tested.

**Architecture:** Move calculation rules out of `src/ufro_v8_backup.jsx` into focused pure modules under `src/core/`. The React UI becomes a consumer of one calculation result model. Internal recycle, external raw water, product, and final waste are explicit streams with independent flow and quality.

**Tech Stack:** React 19, Vite, JavaScript ES modules, Node built-in test runner, JYN Controller v0.3, Vercel.

**Spec:** This plan is the approved implementation spec from the 2026-09-15 UFRO logic audit.

## Global Constraints
- Preserve current production behavior until replacement calculations are covered by tests.
- TDD for every engineering formula change: failing test -> minimal implementation -> passing test -> commit.
- Never treat TSS reject as part of the UF/RO reject stream.
- Separate gross process feed, external raw water, internal recycle, product, and final external waste.
- UI must not own engineering formulas after Phase 7.
- Do not deploy to production until Phase 8 validation passes.
